One-time setup
StockPulse uses a free Cloudflare Worker as its backend. It fetches from Google News, Yahoo Finance, and 17 other live sources server-side — bypassing all browser CORS restrictions — with no rate limits.
1
Go to workers.cloudflare.com and sign up free. No credit card needed. Free tier = 100,000 requests/day.
2
Create a Worker → delete default code → paste the entire stockpulse-worker.js file → click Deploy.
3
Copy your worker URL (e.g. https://stockpulse.yourname.workers.dev) and paste it below.
Saved only in your browser. Never shared with anyone.
