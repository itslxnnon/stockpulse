Server configuration

Your proxy server URL. The server fetches from Reuters, Google News, Yahoo Finance, CNBC, BBC, MarketWatch, Seeking Alpha and more — zero API keys required.

1
Upload server.js and package.json to a new public GitHub repo named stockpulse-server.
2
Go to render.com → New → Web Service → connect your GitHub repo.
3
Runtime: Node · Build: npm install · Start: node server.js · Instance: Free · Health check path: /health
4
After ~2 min you get a URL like stockpulse-server.onrender.com. Test it at /health — should return {"status":"ok"}.
5
Paste that URL in the Server URL tab. Done — free forever, no API keys.
