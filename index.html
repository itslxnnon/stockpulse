StockPulse Setup

StockPulse uses the Anthropic API with live web search to find and analyse stock news. Your key never leaves your browser — it goes directly to Anthropic.

Stored in your browser's localStorage only. Clearing browser data removes it. StockPulse never stores or transmits your key.

1
Go to console.anthropic.com and create a free account.
2
Click API Keys in the left sidebar → Create Key.
3
Copy the key (starts with sk-ant-) and paste it in the API Key tab. Free accounts include $5 credit.
4
Cost: Each ticker search costs ~$0.005–0.01 USD. $5 credit = 500–1000 searches.
5
Each user needs their own key. When you share the app URL with clients, they enter their own key on first visit.

📡 How to host this app so anyone can access it  ▾
1
Download this file — use the download button (↓) above to save stockpulse.html.
2
Create a free GitHub account at github.com if you don't have one.
3
New repository → click + → New repository → name it stockpulse → set to Public → Create.
4
Upload & rename → drag the file in → commit it → rename it to index.html (click file → pencil icon).
5
Enable GitHub Pages → Settings → Pages → Source: Deploy from branch → Branch: main → Save. Done in ~1 minute.
6
Share the URL: https://YOUR-USERNAME.github.io/stockpulse — works on any device, any browser, no login.
★
Install as mobile app: iPhone → Safari → Share → Add to Home Screen. Android → Chrome → menu → Add to Home Screen.
